# vocaloid-quiz
ボカロ曲のサムネイルで曲名を当てるクイズサイト
https://kagi-web.github.io/vocaloid-quiz/


ボカロ曲のサムネイルを見て、曲名を当てるクイズゲームです。
VocaDBに登録されている楽曲情報をもとに、さまざまなボカロ曲のサムネイルがランダムに出題されます。  







## 遊び方

表示されたサムネイルを見て、楽曲名を考えます。

回答欄に曲名を入力して回答します。

正解すると次の問題に進みます。

3回間違えるとゲーム終了です。








## 楽曲データについて

本サイトでは、楽曲情報の取得に VocaDB を利用しています。
